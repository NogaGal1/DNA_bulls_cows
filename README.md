# DNA Bulls and Cows

## תיאור התוכנית

התוכנית מממשת משחק "בול-פגיעה" עבור רצף DNA באורך ארבעה נוקלאוטידים.

בתחילת התוכנית נוצר באופן אקראי רצף DNA באורך ארבעה תווים, כאשר התווים האפשריים הם:

* A
* C
* T
* G

אותיות יכולות להופיע יותר מפעם אחת באותו רצף.

המשתמש מתבקש להכניס ניחושים עד שהוא מצליח לנחש את הרצף שהוגרל.

עבור כל ניחוש התוכנית מחשבת:

* **Bulls** – מספר האותיות שהמשתמש ניחש נכון וגם נמצאות במיקום הנכון.
* **Cows** – מספר האותיות שהמשתמש ניחש נכון אך נמצאות במיקום שונה.

לאחר שהמשתמש מנחש את הרצף במדויק, התוכנית מדפיסה את מספר הניסיונות שנדרשו.

## מבנה הפרויקט

### scripts/

בתיקייה זו נמצא הקוד של התוכנית.

הקובץ:

`bulls_cows.py`

מכיל את כל פונקציות המשחק ואת התוכנית הראשית.

### input/

בתיקייה זו נמצאים קבצי הקלט של התוכנית.

בגרסה הנוכחית המשחק מקבל את הניחושים באופן אינטראקטיבי מהמשתמש, ולכן אין צורך בקובץ קלט חיצוני.

### results/

בתיקייה זו נשמרות תוצאות הרצת התוכנית.

הקובץ:

`results.txt`

מכיל דוגמה להרצה של התוכנית.

## הפונקציות בתוכנית

### create_quartet()

הפונקציה יוצרת באופן אקראי מחרוזת באורך ארבעה תווים מתוך האותיות A, C, T ו-G.

השתמשתי ב-`random.choice` כדי לבחור באופן אקראי אות עבור כל אחת מארבע העמדות.

### find_bulls(rand_str, guessed_str)

הפונקציה משווה בין הרצף שהוגרל לבין הרצף שהמשתמש ניחש.

עבור כל עמדה נבדק האם שני התווים זהים.

אם התווים זהים, מגדילים את מספר ה-Bulls.

אם התווים אינם זהים, התווים נשמרים בשתי מחרוזות נפרדות:

* `sub_rand` – התווים שלא היו Bulls מתוך הרצף שהוגרל.
* `sub_guessed` – התווים שלא היו Bulls מתוך הניחוש.

הפרדה זו מאפשרת לפונקציה `find_cows` לבדוק לאחר מכן אילו מהתווים נמצאים ברצף אך במיקום שונה.

### find_cows(sub_rand, sub_guessed)

הפונקציה בודקת עבור כל תו ב-`sub_guessed` האם הוא מופיע ב-`sub_rand`.

כאשר נמצאת התאמה, התו מוסר מ-`sub_rand` לפני שממשיכים לבדיקה הבאה.

הסיבה לכך היא שיש להתחשב בחזרות של אותיות. לדוגמה, אם אות מסוימת מופיעה פעם אחת בלבד ב-`sub_rand`, היא יכולה להיספר כ-Cow פעם אחת בלבד, גם אם היא מופיעה מספר פעמים בניחוש.

## אישוש הקוד

בדקתי את הפונקציות באמצעות דוגמאות שבהן יש:

1. ארבעה Bulls.
2. אפס Bulls ואפס Cows.
3. Bulls ו-Cows באותו ניחוש.
4. אותיות חוזרות ברצף שהוגרל.
5. אותיות חוזרות בניחוש.
6. מצב שבו יש יותר הופעות של אות בניחוש מאשר ברצף שהוגרל.

בנוסף, נבדק שהמשחק ממשיך לקבל ניחושים עד לקבלת ארבעה Bulls.
